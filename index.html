REA

Reverse-engineering toolkit; direct merges and one change integrated by the maintainer.

#1533 · Inspect local WASM artifacts

Added WABT-backed, target-free WebAssembly inspection with reproducible artifact and executable evidence shared across CLI and MCP. Reused a mature toolchain rather than introducing a new parser.

Problem
Saved WASM artifacts could not be inspected without an active target.
Approach
Admit an explicitly selected local artifact and pinned WABT tools behind a narrow adapter; preserve digests and CLI/MCP parity.

#2464 · Compare WASM interfaces

Introduced typed import/export comparison so meaningful interface changes can be distinguished from binary encoding differences.

Problem
Changes in binary hashes or WAT type indices do not necessarily imply changed imports or exports.
Approach
Resolve typed interface facts once in the producer and compare retained Evidence without reparsing display text.

#1482 · Inspect PE resources

Made resource identities, file ranges and hashes inspectable while preserving uncertainty and rejecting malformed mappings.

Problem
PE analysts previously had to walk resource directory structures manually.
Approach
Add a bounded PE32/PE32+ inspector preserving numeric versus named identifiers, language, directory and payload ranges, SHA-256 and icon group relationships.

#1506 · Bound framework conventions

Replaced misleading substring heuristics with bounded path and filename matching for Android and Apple artifacts.

Problem
Unrelated filenames were misclassified as Unity or Flutter, and generic Apple paths implied unsupported language/runtime conclusions.
Approach
Match known complete library filenames and framework path segments.

#2214 · Compare inventories using declared coverage

Eliminated false unknown classifications by separating structured coverage facts from diagnostic prose.

Problem
Complete identical inventories were incorrectly reported as unknown.
Approach
Declare traversal scope and completeness at the producer, then compare structured coverage independently of notice text.

#2256 · NIBArchive resource-key joins

Maintainer confirmed that producer-boundary normalization, shared field contract and CLI/MCP coverage were folded into #2248 with coauthor credit. Closed as duplicate, not rejected.

Problem
Decoded NIBArchive objects lost recognized keys needed for asset catalog joins.
Approach
Expose the recognized scalar keys at the NIBArchive producer while retaining original nested values and decode budgets.

#1379 · Dynamic graph sizes in exported models

Fixed message-passing export behavior where Python graph length was specialized to the sample atom count, causing exported models to fail for molecules with different graph sizes. Maintainers requested test changes and subsequently approved the contribution.

Problem
Python len(bmg.V) became specialized to the example molecule during torch.export, breaking inference on different graph sizes.
Approach
Correct message-passing allocation to respect dynamic graph dimensions rather than freezing sample-derived length.

How I contribute

I work on the reliability of existing systems. I preserve information at its source, validate it at system boundaries, and add regression tests where a claim can be checked. I keep changes small enough to review and document the limits of the evidence.

Each entry links to a pull request. A direct merge is recorded by GitHub. Integration requires confirmation from a maintainer and preserved authorship. Acknowledgments, direct commits, reviews and discussions are not listed.

Credit belongs to the upstream maintainers and fellow contributors.
