WHY THIS TOOL EXISTS

An accepted decision can outlive the evidence behind it.

Requirements and documents change. Proofline preserves the original decision and its exact citations while making current review requirements visible.

HOW IT WORKS

From a real problem to a reviewable result.

SCOPE & LIMITATIONS

Know what the evidence proves.

Single-user local scope. No hosted team sync, tenant isolation or organizational identity. Package integrity does not prove source truth. Desktop artifacts remain experimental.

BEFORE YOU START

Questions worth answering.

Is this a shared cloud workspace?

The released scope is local and single-user. Hosted sync, shared workspaces and organizational identity are not included.

Does a verified package prove the source is true?

No. Verification checks integrity. Source truth, authorization and trust in a signing key remain separate questions.
