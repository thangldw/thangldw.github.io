Proofline · v2.0.2 · OPEN SOURCE

Keep the decision. Track the evidence.

Preserve engineering decisions with immutable source versions and exact citations. See when changed evidence requires a fresh review.

Get startedView source

Python tool · Release v2.0.2

HOW IT WORKS

From a real problem to a reviewable result.

01

Capture the reasoning

Bind a decision to an immutable source version and exact citation spans.

02

Detect changed evidence

Keep historical acceptance intact while marking current evidence for review.

03

Verify and share

Verify portable evidence packages and review receipts without a hosted workspace.

TRY THE RELEASED TOOL

Start locally.

python -m pip install proofline-evidence==2.0.2
proofline demo stale-decision
proofline verify-package proofline-demo-stale-decision/evidence.zip
proofline verify-review-receipt proofline-demo-stale-decision/decision-review.json

Synthetic stale-decision report: the decision remains accepted while current evidence requires review.

SCOPE & LIMITATIONS

Know what the evidence proves.

Single-user local scope. No hosted team sync, tenant isolation or organizational identity. Package integrity does not prove source truth. Desktop artifacts remain experimental.
