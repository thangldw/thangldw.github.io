RAGOps · v2.0.2 · OPEN SOURCE

Release AI changes with evidence.

Compare recorded RAG and agent traces against an accepted baseline. Inspect quality and safety regressions before deciding to ship.

Get startedView source

Python 3.11+ · Offline decision core · Release v2.0.2

WHY THIS TOOL EXISTS

A better aggregate score can hide a worse release.

A candidate can improve on average while regressing on a safety slice or citation behavior. RAGOps keeps the baseline, evaluation policy, findings and final decision together.

HOW IT WORKS

From a real problem to a reviewable result.

01

Compare a candidate

Evaluate recorded traces against a baseline with reproducible quality, safety and slice checks.

02

Apply a release policy

Resolve findings into a canonical PASS, WARN or BLOCK decision using a versioned policy.

03

Share the evidence

Export HTML, JSON, Markdown, JUnit or SARIF reports and verify a portable evidence bundle.

THE PRODUCT CONTRACT

Inspect the path from input to outcome.

01

Recorded inputs

Bring baseline and candidate traces into portable scenario contracts.

02

Deterministic evaluation

Inspect quality, safety, slice and distribution evidence.

03

One release decision

Review PASS, WARN or BLOCK, with reports generated from the same decision.

TRY THE RELEASED TOOL

Start locally.

python -m pip install ragops==2.0.2
ragops demo --profile engineer --output ./demo-output
ragops evidence verify --bundle ./demo-output/evidence

Synthetic regression demo. The HTML report displays FAIL; the canonical release decision is BLOCK.

SCOPE & LIMITATIONS

Know what the evidence proves.

Recorded traces are required. The synthetic demo is not production adoption or real-traffic performance evidence. API and workbench integrations are optional adapters.

BEFORE YOU START

Questions worth answering.

Does the demo call an LLM?

The credential-free demo uses recorded synthetic traces. Vendor integrations are optional; a reproducible report does not require an API key.

What does the report prove?

It demonstrates evaluator and release-policy behavior on controlled examples. It does not establish production adoption or real-traffic quality.
