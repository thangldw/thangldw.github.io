RAGOps · v2.0.2 · OPEN SOURCE

Release AI changes with evidence.

Compare recorded RAG and agent traces against an accepted baseline. Inspect quality and safety regressions before deciding to ship.

Get startedView source

Python tool · Release v2.0.2

HOW IT WORKS

From a real problem to a reviewable result.

01

Compare a candidate

Evaluate recorded traces against a baseline with reproducible quality, safety and slice checks.

02

Apply a release policy

Resolve findings into a canonical PASS, WARN or BLOCK decision using a versioned policy.

03

Share the evidence

Export HTML, JSON, Markdown, JUnit or SARIF reports and verify a portable evidence bundle.

TRY THE RELEASED TOOL

Start locally.

python -m pip install ragops==2.0.2
ragops demo --profile engineer --output ./demo-output
ragops evidence verify --bundle ./demo-output/evidence

Synthetic regression demo. The HTML report displays FAIL; the canonical release decision is BLOCK.

SCOPE & LIMITATIONS

Know what the evidence proves.

Recorded traces are required. The synthetic demo is not production adoption or real-traffic performance evidence. API and workbench integrations are optional adapters.
