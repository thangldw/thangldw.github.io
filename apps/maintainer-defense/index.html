HOW IT WORKS

From a real problem to a reviewable result.

01

Inspect the repository

Audit local governance files, workflow permissions, mutable Action references and trust boundaries without a token.

02

Review each finding

Inspect evidence, severity and a stable rule ID. Findings are review leads, not proof of compromise or intent.

03

Propose a reversible patch

Generate a unified diff, check it, and apply through the repository owner’s normal review and CI process.

TRY THE RELEASED TOOL

Start locally.

pipx install maintainer-defense-kit==1.1.1
maintainer-defense audit .

SCOPE & LIMITATIONS

Know what the evidence proves.

Does not execute repository code or inspect live GitHub settings. No field-accuracy, compliance or authorship claims. Patch generation does not modify the target repository.
