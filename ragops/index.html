Start locally

Python 3.11+. Run a disposable local demo.

See example output →
pipx install ragops==2.0.2
ragops demo --profile engineer --output ./demo-output
ragops evidence verify --bundle ./demo-output/evidence

Already have pipx? Use its isolated environment. Otherwise choose Python venv (macOS/Linux) or From source (macOS/Linux commands).
