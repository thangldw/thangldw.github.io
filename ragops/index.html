Start locally

Python 3.11+. Run a disposable local demo.

See example output →
pipx install ragops==2.7.1
ragops demo --profile engineer --output ./demo-output
ragops evidence verify --bundle ./demo-output/evidence

Already have pipx? Use its isolated environment. Otherwise choose Python venv (macOS/Linux) or From source (macOS/Linux commands).

Everything in RAGOps

Every command runs offline, makes no network call and needs no model provider (counterfactual calls only the command you give it).

Start from your own logs

init turns your RAG logs into a first scenario, baseline and comparison report; demo runs a credential-free example; inspect shows benchmark coverage.

Compare and gate

evaluate, compare and slice-aware gate-v2 give one PASS, WARN or BLOCK; explain says in plain words why a gate failed; ci-render writes JSON, Markdown, HTML, JUnit, SARIF and GitHub Summary.

Agents and imports

trace converts and evaluates agent trace graphs; adapters import Phoenix, Ragas, DeepEval, LangSmith, MLflow, Promptfoo and custom JSON.

Statistical rigor

collect-runs, compare-runs and compare-sequential compare repeated runs with uncertainty-aware gates; stability blocks answers that vary between repeats.

Evidence and provenance

evidence bundles are verifiable offline; baseline-create, baseline-sign and baseline-verify protect the accepted baseline; diagnose-provenance and detect-evaluator-drift tell model, evaluator and data changes apart.

Trust the scorer where it is accurate

calibrate measures the scorer against your human labels and finds where it can be trusted; triage sends only the uncertain cases to a person.

Grow the tests from production

policy-suggest drafts a release policy from your baseline; mine adds thumbs-down, low-rating and escalated logs to the scenario as regression cases.

Do answers depend on evidence?

counterfactual removes or alters the evidence, plants an instruction or drops a citation and re-asks your system; counterfactual-selftest checks those checks on your own cases first.

Teams and governance

governance manages governed artifacts and blind reviews; history, review and trend read saved runs; serve runs the local API and workbench; pilot-init and pilot-report record design-partner evidence. Workspaces are alpha.

Use it from your AI assistant: plugins for Claude Code/Cowork, ChatGPT and Codex.

The newer commands (policy-suggest, calibrate/triage, stability, mine, counterfactual) were exercised on toy systems and constructed data only; not yet measured on a real production RAG system. Read documentation →

Recorded trace format

Each file is a JSON array with one entry per scenario case. This excerpt is from the demo baseline.json; the scenario file defines thresholds and required citations.

[
  {
    "case_id": "demo-procedure",
    "answer": "Stop A1000, inspect the cooling fan guard, remove debris, and restart below 60C.",
    "citation_ids": [
      "manual-a1000-e42"
    ],
    "latency_ms": 850,
    "cost_usd": 0.008
  }
]
Statistical gates and limits

For larger replay bundles RAGOps also offers a paired hierarchical bootstrap comparison and a sequential comparison. Lexical groundedness is token overlap between answer and evidence, not semantic verification, and evidence verification checks integrity, not model safety.

Reports & integrations

Export HTML, JSON, Markdown, JUnit, SARIF and GitHub Summary. API/workbench and vendor adapters are optional. The core does not make network calls. Evidence verification checks integrity, not model safety.
