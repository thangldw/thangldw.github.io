How I contribute

My focus is on making existing systems more trustworthy: preserve information at its source, validate contracts at boundaries, reduce false confidence, and add targeted regression evidence. I favor small, reviewable extensions over parallel infrastructure and avoid claiming certainty where evidence is incomplete.

Evidence policy: “merged” means GitHub records a direct merge; “integrated” requires maintainer confirmation; “acknowledged” does not imply code adoption. Counts reflect the reviewed public record, not a complete lifetime GitHub contribution total.
