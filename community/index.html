Engineering decisions and trade-offs

Open a case to read the problem, the implementation choice and its limits. Each note is based on the public PR record.

REA #2214 · Data contracts Make coverage a typed fact, not a diagnostic string
Problem
Complete identical inventories were incorrectly reported as unknown.
Decision
Declare traversal scope and completeness at the producer, then compare structured coverage independently of notice text.
Why
Display messages can change without changing evidence semantics; consumer-side string heuristics are fragile.
Trade-off
A slightly richer evidence contract in exchange for deterministic comparisons and fewer false unknowns.

PR evidence · #2214

REA #1533 · Build versus reuse Use WABT rather than invent a WASM parser
Problem
Saved WASM artifacts could not be inspected without an active target.
Decision
Admit an explicitly selected local artifact and pinned WABT tools behind a narrow adapter; preserve digests and CLI/MCP parity.
Why
Reuse a maintained decoder while constraining the trust boundary and provenance.
Trade-off
A caller-supplied external toolchain instead of a new in-process parser.

PR evidence · #1533

REA #2464 · Semantic comparison Compare typed interfaces, not byte-level differences
Problem
Changes in binary hashes or WAT type indices do not necessarily imply changed imports or exports.
Decision
Resolve typed interface facts once in the producer and compare retained Evidence without reparsing display text.
Why
The comparison should answer API compatibility questions rather than file-identity questions.
Trade-off
Duplicate names or incomplete inventories remain unknown rather than forcing a misleading verdict.

Chemprop #1379 · Dynamic shapes Prevent export-time graph-size specialization
Problem
Python len(bmg.V) became specialized to the example molecule during torch.export, breaking inference on different graph sizes.
Decision
Correct message-passing allocation to respect dynamic graph dimensions rather than freezing sample-derived length.
Why
An exported model must preserve the intended variable-size molecular graph contract.
Trade-off
Focus on the dynamic graph-size defect, with regression coverage, rather than redesigning message passing.

PR evidence · #1379

REA #1506 · Heuristics Prefer bounded conventions over substring inference
Problem
Unrelated filenames were misclassified as Unity or Flutter, and generic Apple paths implied unsupported language/runtime conclusions.
Decision
Match known complete library filenames and framework path segments.
Why
Weak substring matches turn naming coincidences into false evidence.
Trade-off
Narrower detection may yield fewer hints but substantially more defensible ones, without schema changes.

PR evidence · #1506

Sony NMOS #502 · Standards Represent temporal redundancy explicitly
Problem
Existing SDP handling did not fully express the SMPTE 2022-7 temporal redundancy form.
Decision
Retain SSRC-level identity, CNAME, delay and MID in structured parameters, with round-trip and invalid-input tests.
Why
Protocol conversions must preserve semantics and reject transport layouts that cannot be represented faithfully.
Trade-off
Constrain the supported topology rather than silently coercing incompatible forms.

PR evidence · #502

OpenMed #1601 · Privacy correctness Use context-gated deterministic identifiers
Problem
Vietnamese identifiers and contact formats were missing from offline PII recognition.
Decision
Add locale-specific patterns and require context for CCCD/CMND candidates that lack a public checksum.
Why
Treating every matching digit sequence as a national ID creates avoidable false positives.
Trade-off
Context gating can miss isolated identifiers; synthetic golden cases make this limitation testable.

PR evidence · #1601

Diagram Design #101 · Visual correctness Specify a quantitative visual contract
Problem
Adding a polar example alone would not guarantee faithful quantitative encoding.
Decision
Define angle/radius semantics, zero baseline, accessible variants and adversarial geometry checks.
Why
Visualizations should be validated against measurable semantics, not appearance alone.
Trade-off
Intentionally restrict the supported variants to keep verification tractable.

More engineering decisions

Six more cases cover binary inspection, CI, identifier validation, workflow portability and documentation.

REA #1482 · PE resources Expose exact resource identities without decoding payloads
Problem
PE analysts previously had to walk resource directory structures manually.
Decision
Add a bounded PE32/PE32+ inspector preserving numeric versus named identifiers, language, directory and payload ranges, SHA-256 and icon group relationships.
Why / trade-off
Keeping payload formats opaque avoids a broad decoder surface; malformed ranges or exhausted budgets fail rather than returning partial success.
Value
Inspectable forensic evidence with explicit file offsets and identity.

PR evidence · #1482

xDSL #6252 · CI correctness Enable a lint rule without changing runtime semantics
Problem
The HW dialect had redundant __post_init__ defaults duplicated from InitVar fields.
Decision
Remove only redundant defaults and enable Ruff RUF033, backed by functional tests.
Why / trade-off
A narrowly scoped lint adoption avoids behavioral refactoring and retains dataclass construction compatibility.
Value
Cleaner enforceable CI convention with minimal regression risk.

PR evidence · #6252

OpenMed #1593 · National-ID validation Validate Hungarian TAJ with a real checksum
Problem
A language pack needs to distinguish plausible nine-digit sequences from structurally valid national identifiers.
Decision
Use the documented alternating 3/7 checksum, locale-specific formats, synthetic surrogates and offline golden tests.
Why / trade-off
Checksum validation is stricter than regex-only detection; synthetic fixtures avoid using real personal data. Pattern-based coverage remains locale-bounded.
Value
Deterministic TAJ detection and anonymization support.

PR evidence · #1593

Hatena #193 · Workflow portability Resolve working directories without new caller configuration
Problem
Blog workflows assumed the configuration lived at the repository root.
Decision
Find the single tracked blogsync.yaml, use its parent directory consistently for draft processing, change detection and uploads.
Why / trade-off
Automatically resolving a unique tracked config avoids new workflow inputs; missing or ambiguous configuration fails explicitly.
Value
Supports subdirectory layouts while preserving existing caller contracts.

How I contribute

I work on the reliability of existing systems. I preserve information at its source, validate it at system boundaries, and add regression tests where a claim can be checked. I keep changes small enough to review and document the limits of the evidence.
